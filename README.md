# 实盘基金跟踪 · Fund Tracker

实盘基金持仓跟踪面板，集成到交易工作台。数据从天天基金自动同步。

## 功能

- 双主题（亮色暖白 / 暗色金融），跟随工作台主题自动切换
- 每只基金：最新净值、净值日期、持仓份额、成本价、总成本、市值、累计盈亏、收益率
- 汇总：总成本 / 总市值 / 累计盈亏 / 总收益率
- 数据由 GitHub Actions 每天自动同步，无需手动更新

## 目录结构

```
fund-tracker/
├── index.html              # 跟踪面板（引用远程设计系统）
├── data/funds.json         # 持仓 + 最新净值（自动更新）
├── scripts/sync_funds.py   # 天天基金净值同步脚本
└── .github/workflows/sync.yml  # 每日自动同步（北京时间 18:30）
```

## 手动同步

```bash
python3 scripts/sync_funds.py
```

- 两只均为 QDII 基金，净值 T+1/T+2 更新，无盘中实时估值
